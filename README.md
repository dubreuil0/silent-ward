# Silent Ward · Sessiz Koğuş

**A first-person 3D horror game made entirely by AI.**
Every line of code, the level layout, the story and notes, the creature, the shaders and all of the sound
were generated by an AI model (Claude) from a short prompt. Textures and props come from
[Poly Haven](https://polyhaven.com) (CC0). Built with Godot 4.7.

[⬇ Download for Windows](../../releases/latest) · English & Türkçe

---

## English

It is 1987. Your sibling vanished inside the abandoned **Saint Halvard Asylum**. You went in after them, and the
door locked behind you. Find five fuses, restart the generator in the basement and escape through the main door.

Something walks the corridors. **The Nurse** is blindfolded: she cannot see, but she hears everything and she is
drawn to light.

### Controls

| Key | Action |
| --- | --- |
| WASD | Move |
| Shift | Run (uses stamina, makes noise) |
| Ctrl / C | Crouch (silent) |
| F | Flashlight (drains battery) |
| E / Left click | Interact |
| Right click / Space | Hold your breath while hiding in a locker |
| ESC | Pause |
| F11 | Toggle fullscreen |

The language can be changed in **Settings**.

### Running the game

1. Download `SilentWard-Windows.zip` from the [latest release](../../releases/latest) and extract it.
2. Run `SilentWard.exe`. Windows 10/11 64-bit and a Vulkan-capable GPU are required.
3. The executable is not code-signed, so Windows SmartScreen may warn you: choose *More info → Run anyway*.

### Building from source

Open the folder in Godot 4.7, or export from the command line:

```
godot --headless --path . --export-release "Windows Desktop" build/SilentWard.exe
```

Developer tools in `tools/`:

```
godot --headless --path . --script res://tools/gen_audio.gd          # regenerate all sounds
godot --headless --path . res://scenes/game.tscn -- --autotest=A     # automated tests A / B / C / D
godot --path . res://scenes/game.tscn -- --shots=<folder>            # screenshot tour
```

## Türkçe

Yıl 1987. Kardeşin terk edilmiş **Saint Halvard Akıl Hastanesi**'nde kayboldu. Peşinden içeri girdin ve kapı
arkandan kilitlendi. Beş sigortayı bul, bodrumdaki jeneratörü çalıştır ve ana kapıdan kaç.

Koridorlarda bir şey dolaşıyor. **Hemşire**nin gözleri bağlı: göremez ama her şeyi duyar ve ışığa yönelir.

### Kontroller

| Tuş | Eylem |
| --- | --- |
| WASD | Hareket |
| Shift | Koş (stamina harcar, ses çıkarır) |
| Ctrl / C | Eğil (sessiz) |
| F | Fener (pil tüketir) |
| E / Sol tık | Etkileşim |
| Sağ tık / Boşluk | Dolapta saklanırken nefesini tut |
| ESC | Duraklat |
| F11 | Tam ekran aç/kapat |

Dil **Ayarlar** menüsünden değiştirilebilir.

### Oyunu çalıştırma

1. [Son sürümden](../../releases/latest) `SilentWard-Windows.zip` dosyasını indir ve klasöre çıkar.
2. `SilentWard.exe` dosyasını çalıştır. Windows 10/11 64-bit ve Vulkan destekli bir ekran kartı gerekir.
3. Dosya dijital olarak imzalı olmadığı için Windows SmartScreen uyarı verebilir: *Ek bilgi → Yine de çalıştır*.
